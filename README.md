# Gambl Roulette

A premium European roulette game for desktop and mobile, built for the FantomZone game collection.

## Features

- Menu-first casino lobby with rules and table settings
- 37-pocket European wheel with animated ball and result history
- Straight-up, dozen, column, red/black, odd/even, and low/high betting
- Responsive mobile Wheel / Betting Board switch with a persistent chip rack
- Live dealer question, countdown, synthesized voice, and casino sound effects
- Local preferences for sound, bankroll, table limits, and chip denominations

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.
